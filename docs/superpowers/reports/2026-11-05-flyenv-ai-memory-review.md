## 实施过程的决定与代价（按发生顺序）

以下对应执行记录中的前 17 条 Ruling；随后 11 条是审查者未作结论的范围。没有用审查通过替代这些边界。

1. 复用已有依赖，只隔离新增原生依赖，避免影响原仓库的 postinstall；代价是外部依赖环境仍可能漂移。
2. 原仓库任务稿和 registry 改动保留，仅复制获批方案及计划；后续集成需明确携带相关文档，不能误以为已同步原仓库。
3. 为实际客户端增加仅用于评估的 MCP harness/schema；手写别名是合成对照，误当成 Agent 扩词会夸大效果。
4. 等待临时客户端审批时，仅推进独立的原语验证，阶段 A 保持未完成；审批不通过时，这部分前置工作可能无法用于当前方案。
5. 阶段 A 仅作为构造数据的初步效果门槛，长任务和真实客户端对照放到任务 12；若后续表现不同，需要重新评估检索效果，不能提前承诺节省 token 或普遍自动捕获。
6. 本机 Electron 随宿主退出，因此另用真实 Node 孤儿进程验证同一租约；平台生命周期差异仍未被这一替代样例覆盖。
7. 将原仓库被忽略的既有 MCP 测试复制并纳入版本控制，更新基线已存在的 ClickHouse 预期；如果对基线判断错误，可能掩盖能力回归，因此没有对应修改生产能力。
8. 阶段 B 用隔离的最小 Electron 宿主加载生产组件；它本身不覆盖完整应用，完整 Application 冒烟另放到任务 12。
9. 删除恢复逐个读取有上限的 JSON，但不受搜索总字节预算阻断；保证超容量仍能清理，代价是大范围首次访问的恢复时间可能较长。
10. warnings 保持在既有 MemoryResult 外层，整个响应一并计入预算；误按任务简述读取 SearchPage 内层的调用方需要改用共享协议。
11. 通用 MCP 适配层允许插件明确覆盖 isError，保留 mutation partial 的失败语义；插件自身可能错误分类，但原始 outcome/回执仍保留。
12. 完整 UI 测试排空 worker 后直接退出，避开与记忆任务无关的系统 hosts 清理；这不能覆盖完整产品退出与其他服务的组合行为。
13. 用测试 HTTP 代理将一次已提交回执替换为 unknown，验证原请求精确重放；这不等于穷尽实际断线、重连和所有传输时序。
14. 最终评估使用 40 道冻结构造题、8 道实际客户端题、长日志及新会话；解析模型和上下文预算未完全受控，真实长任务的效果与成本可能不同。
15. baseline 得分是对照测量，不要求必然满分，生产 MCP 的 8/8 门槛保持不变；可能漏判比较器问题，因此补齐 scope 元数据并成对重跑，保留首轮失败。
16. 超大合法搜索结果只省略传输元数据并标记 metadata_omitted，完整排名、存储和 get 不变；忽略标记的客户端可能遗漏摘要/来源细节，规则和 UI 提示其读取 get。
17. 成功回滚后沿用旧安装代次，仅在实际退出且恢复成功后重新开放懒加载派发；恢复入口若被误用可能重新开放不安全状态，因此 Registry 拒绝剩余 owner/opening、全局关闭和代次不符，回滚失败不调用恢复。

## 审查者未作结论的范围与处理决定

以下均保留为验证边界，不由审查通过推导出额外承诺：

1. Windows、Linux、macOS Intel 等平台：继续限制 manifest 为 macOS ARM64；误推成本是未经验证的原生锁/文件系统行为。
2. 任意断电持久性及 SSD 安全擦除：不声明；进程崩溃测试不能证明设备级行为。
3. 网络文件系统、在线同步及运行中手工替换数据库/锁：不支持，维护要求停用后复制一致快照；误用可能破坏唯一所有者假设。
4. 同一 OS 用户下的恶意进程或互不信任 Agent 隔离：不是多租户安全边界；不能据本地 MCP 认证推断这种隔离。
5. 自动记忆的普遍性、多小时真实使用及强制上下文压缩：只声明构造长日志/新会话的观察结果；真实使用可能漏存。
6. 严格模型/上下文预算等价和 token 节省：没有足够控制，不做收益承诺；小样例的工具调用开销可能更高。
7. Claude 和其他客户端：按用户指定只验收 Codex、Kimi；通用 MCP 兼容不等于客户端实测。
8. 最终签名安装包：本轮提供插件构建和原生依赖 ASAR 探针，不宣称所有发行包已验证；发行前仍需安装包验收。
9. 完整应用退出与无关服务/hosts 的交互：UI 冒烟刻意绕开系统清理；专属 worker 生命周期独立验证，整个退出组合仍可能存在额外问题。
10. 巨大历史库、精确堆上界及性能保证：维持实测默认预算；生成千条样例不代表所有个人长期库。
11. 自动安装规则、历史时间线/回滚、路径重绑定、共享 worktree、在线备份导入、语义搜索、主动工具通知：仍按 V1 后置；需要这些能力的用户暂时需手工维护或等待后续版本。
