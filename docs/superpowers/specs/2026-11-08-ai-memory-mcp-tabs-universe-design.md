# AI Memory：MCP 工具分组与 3D 记忆星图

## 目标

1. FlyEnv MCP 的工具页按内置工具与插件划分 Tab，不再混排；只展示已安装且启用插件的工具。
2. 移除 AI Memory 左侧栏的独立 MCP 开关，插件可用状态完全由安装和启用状态决定。
3. 在保留现有记忆管理能力的前提下，将默认管理视图升级为可交互的 3D 记忆星图。

## 方案选择

采用原生 Canvas 2D 绘制三维投影，不新增 Three.js 等依赖。备选方案为 CSS 3D DOM 节点和引入 WebGL 引擎：前者连线和深度排序较弱，后者增加依赖与包体。原生投影可以实现旋转、缩放、深度、连线和命中检测，并便于用纯函数测试。

## MCP 工具分组

- `PluginMCPRegistration` 和 `MCPRuntimeTool` 增加通用 `pluginName`，由 `PluginManager` 从已启用插件 manifest 传入，经 `PluginMCPRegistry.listTools()` 返回。
- 新增纯函数按 `pluginId` 分组：无 `pluginId` 的工具属于 FlyEnv 内置组；插件组使用 `pluginName`，缺失时回退为 `pluginId`。
- `Tools.vue` 使用 `el-tabs`。每组保留“启用工具”和“审批”两个现有区域，工具开关与审批继续调用 `MCPSetup`，不改变权限默认值。
- 分组完全基于 `mcp:listTools` 的实时目录。主进程现有 `getMCPRegistrations()` 已排除未安装、停用或缺少安装代次的插件，不在渲染层复制启用判断。
- 当前组随工具目录刷新而消失时，回退到内置组。

## 插件状态与侧栏

- `aside.vue` 只保留模块入口和图标，不再读取 MCP 运行状态或加载连接。
- 图标可用态为 `true`：该 aside 仅在插件已安装且启用时由宿主加载，与需求中的判定来源一致。
- 删除 `MemoryController.setMcpEnabled()` 及 manager 中仅供该开关使用的 `startGateway`、`setMemoryTools` 依赖。
- 保留 Agent 接入页的 MCP 状态检查、客户端配置和通用 MCP 工具权限设置；这些不是独立可用性开关。
- 删除对应开关测试和不再使用的中英文案。

## 3D 记忆星图

### 数据与布局

- 输入为当前 `SearchHit[]`，沿用现有作用域、搜索、筛选、状态和分页，不新增全量扫描或存储字段。
- 节点位置由记忆 ID 的稳定哈希确定，并按类型/主题形成空间聚类；相同数据刷新后布局不跳动。
- 相同主题或共享标签生成关联线。连线只表示元数据关联，不伪装成数据库存储的语义关系。
- 节点颜色表示记忆类型；置顶节点更大并有强调光晕；归档或过期节点降低亮度。
- 使用旋转矩阵、透视投影和深度排序绘制，背景包含轻量星点与网格。

### 交互与组件边界

- 新增 `MemoryUniverse.vue` 负责 Canvas 生命周期和交互，新增纯函数模块负责布局、关联、投影和命中计算。
- 默认显示星图，可切换现有表格列表；星图点击节点复用 `select(hit)` 打开既有详情抽屉，编辑、归档、恢复和删除流程不变。
- 支持拖拽旋转、滚轮/按钮缩放、自动巡航开关和重置视角；悬停显示标题、类型、主题和摘要。
- 页面显示当前节点数、关联数、类型图例和操作提示。空结果、错误、警告、项目选择与分页继续沿用现有 UI。
- 组件视图状态、悬停和相机属于挂载组件；搜索、详情与写入仍由 `MemoryManager` 持有。
- `requestAnimationFrame` 和 `ResizeObserver` 在卸载时清理；自动巡航默认关闭，由用户显式开启，静态视图仅在交互或数据变化时重绘。Canvas 不可用时保留列表入口，不影响管理操作。

## 状态与操作契约

本次不新增长时间运行操作或进程。现有搜索由 `MemoryManager` 拥有，重复搜索使用序列号避免旧响应覆盖；现有写入仍为单 flight，并保留 unknown 结果阻止重放的规则。星图只消费结果，不发起独立 IPC，不改变终态和清理语义。

工具启停与审批是相互独立的单项操作，沿用现有结果处理。插件目录刷新失败时保留现有目录，不伪造插件可用状态。视觉渲染或提示失败不影响已完成的搜索与写入。

不新增 Pinia、共享配置或模块生命周期接口；不申请模块边界例外。

## 验证

- MCP 分组纯函数：内置/多插件分组、名称回退、顺序与空目录。
- 插件注册表：返回 `pluginName`，停用后目录仍由现有机制移除。
- 星图纯函数：稳定布局、主题/标签关联、无关联节点、投影与命中边界。
- 更新控制器测试，确认移除独立 MCP 开关后状态检查仍可用。
- 运行 AI Memory 全部测试、插件构建、MCP 注册表测试、renderer operation boundaries 检查及相关类型/格式检查。
- 通过应用级 smoke 或实际渲染验证：启用插件时出现对应 Tab，停用后消失；侧栏无开关；星图可旋转、缩放、选择节点并打开详情，列表仍可管理记忆。

## 假设

- 星图展示当前搜索页而非跨分页全量数据，以保持现有搜索容量与游标语义。
- 保留列表作为可访问性和精确管理入口，默认使用星图。
- 自动执行模式下不等待额外视觉稿审阅，不引入新依赖，不改变插件数据协议。
