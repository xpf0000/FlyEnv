# AI Memory 3D 神经记忆体 Three.js 静态预览设计

## 目标

制作一个独立静态页面，先验证 `docs/task/flyenv-ai-mem-star-map.md` 的视觉方向、真实 WebGL 效果和基础交互，再决定正式实现。预览不修改 AI Memory 插件、真实记忆数据、MCP 工具或持久化格式。

## 交付形式

在 `tmp/ai-memory-neural-preview/` 创建 HTML、CSS 和 TypeScript 预览源码，使用项目现有 Vite 提供本地 HTTP 服务。新增本地 `three` 依赖并更新 `package.json` 与 `yarn.lock`，不使用 CDN、远程资源或模拟后端。

预览通过 Three.js 的 `WebGLRenderer`、`BufferGeometry`、`Points`、`LineSegments` 和相机投影渲染。预览页面与正式插件组件分离，不直接替换现有星图。

## 模拟数据与布局

- 使用八种现有记忆分类及文档指定配色。
- 创建八个主神经节点和约 160 个确定性模拟记忆节点，刷新页面布局保持一致。
- 主节点分布在不同三维深度，不使用规则八边形或太阳系轨道。
- 每类形成局部神经簇，整体通过三维分布和连接自然形成近似球形或椭球形，不绘制实体球壳。
- 节点大小仅使用预览明确声明的模拟关联数，不把模拟字段带入正式业务模型。

连接分为两类：

1. 模拟语义关系：较清晰，用于悬停和选中反馈。
2. 装饰性神经纤维：更细、更暗，仅增加结构密度，不在界面中冒充真实关联。

## 视觉表现

- 深黑蓝背景，少量琥珀金电路和数据轨迹。
- 主节点使用能量核心、柔和光晕、结构环和克制脉冲。
- 子节点使用共享几何体和批量渲染，呈现大小不同的发光光点与轻微漂浮。
- 少量粒子沿连接线移动，连接线按深度和距离分级显示。
- 默认只显示分类标签及记忆数量；子节点标题和摘要仅在悬停或选中时出现。
- 不显示中心人脑、巨大 Logo 或“AI 记忆体”文字。

## 交互

- 拖拽旋转、滚轮缩放、重置视角。
- 自动旋转默认开启，以便评审动态效果；可暂停。
- 点击主节点平滑聚焦该分类，其他分类降低亮度，并显示该分类模拟记忆列表。
- 点击子节点高亮其模拟语义关系，并显示标题、摘要、类型、标签和关联数。
- 双击节点聚焦，提供返回完整记忆体视图。
- 使用 Three.js Raycaster 或等价的批量点拾取方式完成节点选择。
- 页面隐藏时暂停渲染，退出预览后停止本地服务；预览销毁时释放 WebGL 几何体、材质和渲染器资源。

## 验收

- 远看形成密集、有层次的神经网络聚合体，而非八节点规则平面关系图。
- 中距离能辨认八个分类簇，近看能观察单个模拟节点和连接。
- 装饰线与可选中的语义关系具有明确差异。
- 拖拽、缩放、分类聚焦、子节点详情、自动旋转开关和重置均可用。
- 160 个模拟节点下交互流畅，控制台无 WebGL 错误。
- 预览只生成临时页面文件及明确的 Three.js 依赖改动；正式接入前由用户确认视觉方向。
