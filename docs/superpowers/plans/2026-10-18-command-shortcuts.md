# Command Shortcuts Implementation Plan

**Goal:** 在 FlyEnv 中用文件夹树管理预设命令，并在指定目录的系统终端执行。

**Architecture:** 独立 `plugins/command-shortcuts` 插件；Vue 页面与两个弹窗只拥有表单、选择、展开状态；`reactiveBind` 单例控制器拥有文件夹目录、持久化和执行生命周期；Fork 拥有路径检查和终端启动。

**Scope:** 文件夹卡片显示字符图标、名称、路径、编辑、添加命令、删除文件夹（确认）；内部命令项目显示说明、原始命令、编辑、删除（确认）、执行。两层均可拖动排序。添加/编辑文件夹可选目录；命令允许多行。英文/中文插件本地翻译，其他语言回退英文。

## 0.1.1 卡片与排序调整

- 用户要求取消表格，整体对齐启动组：同样的标题/主滚动区、响应式 1/2/3 列卡片、卡片标题与路径、248px 命令滚动区域、底部添加/编辑/删除操作；命令项目使用紧凑边框卡片和执行/编辑/删除按钮。
- 文件夹与同文件夹内的命令均使用现有 vuedraggable 的专用手柄拖动；两层独立，不跨文件夹移动命令。拖动只调整组件本地草稿，排序保存由现有单例 controller 及 saving 互斥拥有。
- 排序契约：开始为拖动结束提交完整 ID 快照，终态为 Storage 写入成功/失败；无中间事件、不发送 IPC、不启动或停止服务；保存成功才发布新目录，失败保留原目录并恢复草稿；重复调用/同时编辑由 saving 拒绝。离开/重入不丢失正在保存的操作。
- 校验完整排列（长度、唯一性、归属），无效顺序不写入、不丢弃条目；无顺序变化不写入。保存失败仅影响该次排序，不改变命令执行状态或重放终端请求。保持 V1 存储键/结构，数组顺序自然向后兼容。
- 计划：先增加排序持久化/无效顺序/失败恢复/互斥回归；再替换页面并提取 FolderCard；更新边界断言、文案与 0.1.1 版本；验证拖动、刷新、空态和深浅色布局，构建检查产物。
- 此次无共享配置、Pinia、公共生命周期修改或例外授权；终端执行契约保持现状。

## Constraints and operation contract

### 0.1.2 首字符图标与目录打开

- 采用插件市场48px圆角渐变首字符图标，移除图标输入；读取V1旧数据时忽略旧icon，不影响目录、命令和顺序。
- 路径展示使用yellow-500，点击打开系统文件管理器；卡片footer新增「在终端打开」，无预设命令也可使用，只cd目录。
- 路径打开与目录终端均由模块单例controller拥有请求快照、重复保护、错误和终态，跨页面保留。目录终端复用现有Fork入口与路径校验，code200中间事件及终态监听清理不变，不登记服务PID。
- 必要目录检查和系统启动失败只影响本次操作；不更改数据，不重放命令。Mac只发送cd，Linux保留Bash，Windows编码脚本-NoExit直接Set-Location，不使用命令执行结果/按键等待界面。
- 保持V1 Storage，无共享配置/Pinia/公共生命周期例外；增加旧数据、目录终端/路径打开快照与单飞/失败、跨平台cd模式回归，再完成UI与包验证。

- 无例外授权：仅 StorageGetAsync/StorageSetAsync 独立键，不写 config.setup、不新增 Pinia、不修改共享服务类型。
- 非服务插件，终端命令不属于 ModuleInstalledItem 服务启停；终端和命令由用户在终端中管理，FlyEnv 不登记 PID、不在退出时杀终端。
- 文件夹与命令通过稳定 ID 关联。单例加载单飞；存储缺键/过期视为首次使用，其他错误禁止覆盖原数据。保存成功后才替换内存目录，保存串行禁止并发修改；失败保留已有数据和表单。
- 执行 owner：模块单例控制器；lifetime：点击至系统终端交接完成，可跨页面离开/重入；快照：文件夹路径、命令 ID、原始命令；中间：code=200 保留 busy；终态：code=0（交接成功）/1（失败）/超时（结果未知，不重试）；同一命令执行中忽略重复点击，其他命令独立。
- 必要依赖：输入合法、目录存在且是目录、终端启动；任一步失败只影响本次执行，不自动重试命令。不把终端打开成功表述成命令执行成功。终端打开后的命令退出码由终端显示。
- 终端：macOS Terminal（AppleScript 参数传递、完整转义），Windows PowerShell（复用宿主编码终端脚本及环境同步），Linux 常见终端（参数数组启动 bash，启动事件即交接）。Windows 使用 PowerShell 语法，Unix 使用终端 shell 语法。运行时再次切换目录，切换失败不得执行用户命令。
- 目录字符串必须绝对路径、非空、不含 NUL；预设命令不改写用户内容，不记录到日志。
- 无需修改宿主业务入口，manifest/Module/aside 自注册；构建 registry 只增加本插件条目，保留工作区现有 llama.cpp 改动。
