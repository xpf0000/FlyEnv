## 操作契约

- **main 生命周期**：ForkManager 拥有已受理请求的在途记录，ServiceProcess 拥有运行登记，Application 拥有退出生命周期。退出先关闭启动/面板打开入口，再结算已受理操作的登记，最后逐实例停止。UI/MCP/退出复用同一实例参数；停止终态只注销派发时绑定的那一代。重复退出共享 Promise，停止失败保留登记且继续其他实例。保持既有中间事件，code=0/1 为成功/失败终态。
- **fork 服务与面板**：各模块拥有父归属、子孙清单、PID/端口文件和 companion。归属不可读不能当作不存在；确认父后信任其子孙，执行后新鲜查询确认结果。停止失败保留可重试依据，成功才清理文件/状态；面板打开和停止须协调，不能漏掉打开中的进程。
- **数据库原生关闭**：MySQL/MariaDB 模块拥有配置读取、端口/实例核验和既有关闭回退策略；程序使用绝对路径与参数数组，不让密码参与 shell 解析。不向未核对归属的监听者发送 shutdown。
- **权限执行**：Windows 共享执行器拥有授权前目标身份，Helper 拥有签名 RPC 和执行前身份复核；单 PID、端口和树模式一致保护原目标。身份查询权限不足可进入受控授权路径，不在提升后盲目信任数字 PID。正常树仅检查父身份。
- **项目/自定义服务**：fork 模块拥有启动身份和停止参数。避免固定保存空命令凭据；查询暂时失败应允许按可信身份重试，兼容 macOS 缺少完整程序路径或进程标题变化。末次确认覆盖已发现子孙，不增加正常 worker 的停止前校验。

### 操作契约与分工

- main/ForkManager/ServiceProcess 拥有应用寿命内请求、不可变登记和退出：增加遗漏生命周期命令、非生命周期在途跟踪；失败/超时保留未知状态，关闭迟到回包副作用，不能 timeout race 后继续登记新服务。单项失败继续其他实例，成功按派发代次注销。
- renderer 既有对象拥有请求 Promise、进度和通知：启动中停止先结算启动再停止；重复共享 flight；code=200 不改成终态；同步异常/六分钟无终态收口并清监听，停止失败阻止重启、编辑和删除。页面只调用对象，不新增 Pinia/第二套入口。
