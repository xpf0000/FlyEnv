# Command Shortcuts / 快捷命令

按文件夹管理预设命令，在指定目录打开系统终端执行。

1. 点击「添加文件夹」，输入名称，选择或输入绝对路径。图标自动取名称首字符，样式与插件市场一致。
2. 文件夹卡片底部点击「添加命令」，填写说明与命令（支持多行）。
3. 在命令卡片右侧点击执行按钮。命令输出、退出状态和交互输入在系统终端中查看。

界面与启动组保持一致：响应式卡片网格、文件夹标题与路径、可滚动的命令区及底部操作区。拖动文件夹标题左侧手柄调整卡片顺序；拖动命令左侧手柄调整同一文件夹内的命令顺序。顺序自动保存，保存失败恢复原顺序；命令不会跨文件夹移动。

点击黄色路径，在系统文件管理器中打开目录；卡片底部「在终端打开」仅打开终端并进入该目录，不执行任何预设命令，空命令列表也可使用。两种操作均先确认目标是目录。宿主文件管理器接口确认的是已发起请求，不提供文件管理器窗口最终打开结果，插件不会据此显示额外成功通知。

文件夹和命令可编辑或删除；删除文件夹会同时删除预设命令，需确认，不会删除磁盘文件。

macOS 使用 Terminal 的默认 shell，Windows 使用 PowerShell，Linux 使用系统终端中的 Bash。请使用对应 shell 的命令语法。执行前检查目录，目录切换失败不会执行命令。终端交接完成只代表已打开终端，不代表用户命令运行成功。终端由用户管理，离开页面或退出 FlyEnv 不会终止已打开的终端。

数据保存于独立 Storage 键 `flyenv-plugin-command-shortcuts-v1`。插件禁用/升级/卸载不主动删除目录记录或文件；存储读取失败或数据损坏时禁止覆盖，页面提供重试。命令只在用户点击执行时运行，不会在加载插件时自动执行。

开发：`yarn plugin:dev command-shortcuts`。

构建：`yarn plugin:build command-shortcuts`，产物 `dist/plugins/command-shortcuts/command-shortcuts-0.1.3.flyenv-plugin`。

验证：`node --import tsx --test plugins/command-shortcuts/tests/*.test.ts`、`yarn plugin:test command-shortcuts`。

本次验证涵盖控制器/真实 Bash 目录与命令/终端参数回归、插件加载契约、模块边界、lint、构建和归档校验；浏览器使用真实 Vue/Element Plus 界面及隔离存储，目录选择与终端 IPC 使用测试适配器。原生终端完整联调尚未完成；macOS 尝试未获得终端执行结果，测试启动进程已结束并清理，Windows/Linux 尚未实机验收。全仓类型检查保留 53 项其他文件既有错误，本插件无诊断。

Linux Xfce 使用 `--execute` 传递余下参数，依据 [Xfce 官方命令行说明](https://docs.xfce.org/apps/xfce4-terminal/command-line)。终端程序存在且成功创建进程即视为交接，后续终端程序自身的错误由系统终端处理。
